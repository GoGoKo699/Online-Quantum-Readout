# Online Quantum Readout

**How does the arrival order of observable requests change the cost of reading a quantum state?**

The source prepares an unknown pure state through a unitary oracle and remains available while requests arrive. A known finite menu contains bounded Hermitian observables. Each revealed batch must be answered before the next batch is disclosed, while the algorithm may retain arbitrary quantum and classical memory.

The resource of interest is the number of source-unitary and inverse-unitary invocations. Observable-processing gates are a separate resource. The accuracy target for each requested observable is

$$
\left|\widehat\mu_i-\langle\psi|O_i|\psi\rangle\right|\le\epsilon.
$$
